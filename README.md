## 👩‍💻 About Me

I'm a **Software QA Engineer** with hands-on experience testing web applications, APIs, databases, and complex business workflows.

My work involves understanding requirements, designing test scenarios, executing functional and regression testing, investigating defects, validating APIs and databases, and collaborating with developers throughout the software development lifecycle.

I started my QA career primarily with **manual testing** and gradually expanded into **API testing, database testing, performance testing, and test automation**.

Currently, I'm strengthening my automation skills with **Playwright and Selenium** while continuing to build practical testing projects.

---

## 🚀 My QA Journey

My journey in Quality Assurance has been a continuous progression from understanding the fundamentals of software testing to working with more complex systems and automation.

### 🧪 Started with Manual Testing

I began with **manual software testing**, learning how to understand requirements, create test scenarios and test cases, execute tests, identify defects, and write clear bug reports.

### 🔌 Expanded into API & Database Testing

As I gained experience, I started testing **REST APIs using Postman** and validating application data using **SQL and database tools such as DBeaver**.

This helped me understand how the UI, API, and database layers work together.

### ⚡ Explored Performance Testing

I gained experience with **JMeter and K6** to understand performance testing concepts such as load testing, response times, concurrent users, and application behavior under load.

### 🔄 Working with Real-World Applications

My professional QA experience has given me exposure to testing:

* Complex business workflows
* Data-driven applications
* CRUD operations
* REST APIs
* Database changes
* End-to-end user flows
* Regression scenarios
* Integration between different application components
* Production and pre-production environments

I have also worked in **Agile development environments**, collaborating with developers and other team members throughout development, testing, defect resolution, and release cycles.

### 🤖 Moving Deeper into Automation

I'm currently focusing on improving my **test automation skills**, particularly with:

* Playwright
* Selenium
* JavaScript
* API automation
* Reusable automation frameworks
* CI/CD integration

My goal is to combine my manual testing experience and understanding of real-world applications with strong automation skills.
